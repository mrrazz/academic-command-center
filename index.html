🔒 GitHub Private File Access
Personal Access Token (PAT)
Your token is stored only on this device. It is never sent anywhere except directly to GitHub to open your private files. It is not visible after you save it.
Goes to: github.com/settings/tokens → Generate new token (classic) → check repo → generate
📁 How Private Files Work
Once your PAT is saved:
1. Upload any file to github.com/mrrazz/acc-files
2. Click the file → copy the URL from your browser
3. Paste into Files tab → Add File
4. App uses your PAT to open it privately
5. Works on any device where you enter your PAT

✓ Your files stay completely private
✓ No Google. No third parties.
✓ Your data. Your device. Your control.
